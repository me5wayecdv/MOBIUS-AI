06 / QUESTIONS

Reasonable ones.

Does it need an emulator to work?

Static analysis does not. Dynamic testing needs a device: a managed virtual device, a physical phone over adb, or your own lab. The platform talks to it; you keep it.

What happens to my source code?

It stays in the deployment you chose. On-premise and private-cloud installs never send code to us; model calls go to the provider whose key you supplied, and you can run a local model instead.

Is this a scanner that dumps a thousand alerts?

No. A finding is only reported when the path is established and the gate is satisfied; anything uncertain is labelled as undetermined rather than promoted to a vulnerability.

Can it open the fix as a pull request?

Yes, from your pipeline. MOBIUS proposes the patch and retests the original path; the review and the merge stay with your team.

Android only?

The platform is Android-first. The API and device-lab layers are platform-agnostic; iOS support is on the roadmap, not in the box today.
